# Week 6 Projects

This repository contains Week 6 PHP and MySQL web development projects developed using XAMPP, HTML, CSS, PHP, and MySQL.

## Projects

### 1. Student Portal Login System
Features:
- User Registration
- User Login
- Dashboard
- Session Management
- Logout Functionality
- Academic Information
- Unit Registration
- Timetable
- Examination Results
- Notices

### 2. Employee Portal
Features:
- Employee Registration
- Authentication
- Protected Pages
- Session Management
- Logout Functionality

### 3. Multi-User Authentication System
Features:
- Role-Based Authentication
- Student Dashboard
- Lecturer Dashboard
- Administrator Dashboard
- Session Management
- Access Restrictions
- Secure Password Hashing
